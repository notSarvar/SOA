# User Authentication API

## Описание
Этот проект реализует REST API для регистрации, аутентификации и управления пользователями для моего сервиса лояльности.

## Запуск с использованием Docker Compose
```bash
docker-compose up --build
```

## Примеры запросов

### Регистрация пользователя
```bash
curl -X POST http://localhost:8080/register \
     -H "Content-Type: application/json" \
     -d '{
           "login": "testuser",
           "password": "securepass",
           "email": "test@example.com",
           "first_name": "John",
           "last_name": "Doe",
           "birth_date": "1990-01-01",
           "phone": "+1234567890"
         }'
```

### Аутентификация пользователя
```bash
curl -X POST http://localhost:8080/login \
     -H "Content-Type: application/json" \
     -d '{
           "login": "testuser",
           "password": "securepass"
         }'
```

### Получение профиля пользователя
```bash
curl -X GET http://localhost:8080/user/testuser \
     -H "Authorization: Bearer <token>"
```

### Обновление профиля пользователя
```bash
curl -X PUT http://localhost:8080/user/testuser \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer <token>" \
     -d '{
           "first_name": "Johnny",
           "last_name": "Doe",
           "phone": "+9876543210"
         }'
```

## Запуск тестов
```bash
go test ./tests
```

# Описание файлов и папок:
##    cmd/
main.go

Точка входа, где инициализируются все компоненты приложения (например, базы данных, сервисы), а также запускаются HTTP-серверы.

##    config/
config.go

Содержит конфигурацию проекта, например, настройки для подключения к базе данных, JWT ключи и другие переменные.

##    models/

user.go: Модели данных пользователей, например, для регистрации и управления профилем.  \
business.go: Модели данных для бизнес-аккаунтов.\
offer.go: Модели для предложений (скидки, протокоды).\
like.go: Модели для лайков, которые привязываются к предложениям.\
comment.go: Модели для комментариев.\
stats.go: Модели для хранения статистики предложений (просмотры, лайки, переходы).
##    handlers/
Обработчики для работы с HTTP-запросами:

user.go: Обработчики для регистрации, аутентификации и получения/обновления профиля пользователей.\
business.go: Обработчики для работы с бизнес-аккаунтами (регистрация, создание предложений).\
offer.go: Обработчики для работы с предложениями (создание, фильтрация).\
like.go: Обработчики для лайков на предложениях.\
comment.go: Обработчики для комментариев.\
stats.go: Обработчики для просмотра статистики предложений.
##    services/
Логика работы с данными:

auth_service.go: Логика аутентификации и авторизации (например, создание и проверка JWT).\
user_service.go: Логика работы с пользователями (например, создание лайков, комментариев).\
business_service.go: Логика работы с бизнес-аккаунтами.\
offer_service.go: Логика работы с предложениями (например, создание и фильтрация).\
stats_service.go: Логика для работы со статистикой (просмотры, лайки).
##    middlewares/

auth_middleware.go: Мидлвары для аутентификации и авторизации пользователей и бизнесов.

## gateway/
api_gateway.go
API Gateway для маршрутизации запросов к различным сервисам приложения (если используется). Проксирует запросы между микросервисами.

##    tests/
Тесты для различных компонентов приложения:

user_test.go: Тесты для пользователей (регистрация, аутентификация).\
business_test.go: Тесты для бизнес-аккаунтов (регистрация, создание предложений).\
offer_test.go: Тесты для предложений (фильтрация, создание).\
like_test.go: Тесты для лайков.\
comment_test.go: Тесты для комментариев.\
stats_test.go: Тесты для статистики.

##    docs/

api_spec.yaml
Документация для API, описывающая все эндпоинты (формат OpenAPI/Swagger).
