# Сервис статистики

## Зона ответственности
Сервис статистики отвечает за сбор и анализ данных о взаимодействии пользователей с промокодами. Основные функции:
- Сбор статистики просмотров промокодов
- Подсчет лайков промокодов
- Анализ комментариев к промокодам
- Генерация отчетов для бизнесов
- Агрегация данных в реальном времени

## Границы
- Хранит статистические данные в ClickHouse
- Получает события из брокера сообщений
- Предоставляет API для получения статистики
- Не хранит данные пользователей или промокодов
- Не обрабатывает бизнес-логику промокодов
