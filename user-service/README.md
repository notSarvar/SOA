# Сервис пользователей

## Зона ответственности
Сервис пользователей отвечает за управление учетными записями и аутентификацию. Основные функции:
- Регистрация и аутентификация пользователей
- Управление бизнес-аккаунтами
- Хранение профилей пользователей
- Управление ролями и правами доступа
- Управление сессиями пользователей

## Границы
- Хранит данные пользователей в PostgreSQL
- Предоставляет API для регистрации и аутентификации
- Управляет бизнес-аккаунтами
- Не хранит данные промокодов или статистики
- Не обрабатывает платежи или транзакции
