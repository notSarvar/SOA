# API Gateway

## Зона ответственности
API Gateway является центральной точкой входа для всех запросов от пользовательского интерфейса. Он отвечает за:
- Маршрутизацию запросов к соответствующим сервисам
- Агрегацию данных из различных сервисов
- Обеспечение единого интерфейса для UI
- Балансировку нагрузки
- Кэширование ответов
- Ограничение скорости запросов

## Границы
- Принимает HTTP/HTTPS запросы от UI
- Взаимодействует с сервисом пользователей для аутентификации и авторизации
- Перенаправляет запросы к сервису промокодов для работы с промокодами и комментариями
- Получает статистику из сервиса статистики
- Не хранит данные пользователей или промокодов
- Не выполняет бизнес-логику
