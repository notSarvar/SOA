# Сервис промокодов

## Зона ответственности
Сервис промокодов управляет промокодами, скидками и комментариями. Основные функции:
- Создание и управление промокодами и скидками
- Управление категориями промокодов
- Обработка комментариев и ответов на них
- Валидация промокодов
- Отправка событий в брокер сообщений для статистики

## Границы
- Хранит данные промокодов и комментариев в PostgreSQL
- Предоставляет API для работы с промокодами
- Отправляет события в брокер сообщений
- Не хранит данные пользователей
- Не обрабатывает статистику напрямую
